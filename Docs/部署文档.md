# 运行jar
# nohup： 是 "no hang up" 的缩写，它的作用是在后台运行命令，并且不受终端会话的影响。即使你退出当前终端或关闭终端窗口，命令也会继续执行。
# java -jar Surfer-1.0.0.jar --spring.profiles.active=prod： 这是运行 Java 可执行 JAR 文件的命令。它启动一个 Java 应用程序，其中 Surfer-1.0.0.jar 是可执行的 JAR 文件的名称，--spring.profiles.active=prod 是指定 Spring Boot 的配置文件（在这里是 "prod"）。
# Xms 参数用于设置 Java 堆的初始大小，即程序启动时 JVM 为 Java 堆分配的内存大小为 200M。
# Xmx 参数用于设置 Java 堆的最大大小，即 JVM 允许 Java 堆使用的最大内存大小为 200M。
# > /dev/null： 这是将标准输出重定向到 /dev/null，即将输出丢弃。这样做是为了避免在后台运行时产生输出，并确保不会在终端中看到输出。
# 2>&1： 这是将标准错误（stderr）重定向到标准输出（stdout）。这样做是为了确保错误信息也被重定向到 /dev/null，以防止在终端中看到错误输出。
# &： 在命令末尾加上 & 表示将命令放到后台运行。这样终端将立即返回，而不会等待命令执行完成。

ps aux | grep Surfer-0.0.1-SNAPSHOT.jar # 找到进程 ID
kill <PID> # 终止进程
nohup java -jar /opt/blog-server-java/Surfer-0.0.1-SNAPSHOT.jar -Xms200m -Xmx200m --spring.profiles.active=prod > /dev/null 2>&1 &

ps -ef | grep Surfer-1.0.0 # 查看java运行情况
pgrep -f Surfer-0.0.1-SNAPSHOT.jar # 确认进程是否仍在运行
ps aux | grep java # 检查是否有其他类似的进程
curl localhost:8181 # 响应{"timestamp":1753261172999,"status":404,"error":"Not Found","path":"/"}表示成功
